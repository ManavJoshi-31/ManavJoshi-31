## Featured Projects

<details open>
<summary><b>FlowLedger</b> — Secure Financial Workflow & Budget Management Platform</summary>

<br>

A backend-focused platform that replaces email and spreadsheet approvals with a structured financial request workflow. Authorization is enforced at every layer, from identity and role to organization, department, resource ownership and workflow state. Notifications, audit logging, multi-level approvals and the frontend are in progress.

| Attribute | Details |
|:---|:---|
| **Stack** | Node.js · Express.js · MongoDB Atlas · Mongoose · JWT · bcrypt · Postman |
| **Scale** | 8 domain models · 4 roles · multi-organization isolation |
| **Performance** | Stateless JWT-based API |
| **Security** | RBAC with organization, department and resource-level authorization · bcrypt hashing · controlled workflow state transitions |
| **Impact** | A traceable request-to-approval workflow with server-side budget validation |
| **Repository** | [ManavJoshi-31/FlowLedger](https://github.com/ManavJoshi-31/FlowLedger) |

</details>

<details>
<summary><b>Secure Project Management REST API</b> — Role-Based Project & Task Backend</summary>

<br>

A stateless Spring Boot API where organizations manage projects and tasks under strict role-based access control. A solo project with strict Controller, Service and Repository layering, where business rules such as the project deletion guard and task ownership restrictions live in the service layer.

| Attribute | Details |
|:---|:---|
| **Stack** | Java · Spring Boot · Spring Security · Hibernate / JPA · PostgreSQL · Maven · Postman |
| **Scale** | 4 entities · 3-tier RBAC (Admin, Manager, Employee) |
| **Performance** | Stateless design with no server-side sessions |
| **Security** | Spring Security filter chain · BCrypt hashing · custom UserDetailsService backed by PostgreSQL |
| **Impact** | Ownership and deletion rules enforced server-side; entities never exposed directly through the API |
| **Repository** | [Secure-Project-Management---SpringBoot-REST-API-](https://github.com/ManavJoshi-31/Secure-Project-Management---SpringBoot-REST-API-) |

</details>

<details>
<summary><b>DETAMS</b> — Digital Evidence Tracking & Management System</summary>

<br>

A web-based forensic evidence platform that keeps digital evidence tamper-evident and auditable from collection to case closure. A group project built with [Bhavin](https://github.com/Bhavin0608), where I built the evidence management and audit logging modules, including SHA-256 hashing at upload and an immutable CustodyLog.

| Attribute | Details |
|:---|:---|
| **Stack** | Python · Django · PostgreSQL · hashlib (SHA-256) |
| **Scale** | 5 Django apps · 4 roles · 10 custody action types |
| **Performance** | Bulk integrity verification for auditors |
| **Security** | Centralized RBACService · non-editable SHA-256 hashes · 1-hour session timeout · never-cache dashboards |
| **Impact** | A forensically sound chain of custody with tamper detection |
| **Repository** | [Bhavin0608/Digital-Evidence-Tracking-and-Management-System](https://github.com/Bhavin0608/Digital-Evidence-Tracking-and-Management-System) |

</details>
